# Practical 2: Measurement of Tree Height

## Objective
To measure total tree height using a clinometer, hypsometer or laser rangefinder and evaluate repeatability.

## Equipment
Clinometer/hypsometer or laser rangefinder, measuring tape where required, field notebook/mobile form and calculator.

## Procedure
1. Select a tree with a reasonably clear view of its base and top.
2. Establish a suitable observation point.
3. Measure horizontal distance if required by the instrument/method.
4. Sight the tree base and record the base reading.
5. Sight the highest appropriate tree top and record the top reading.
6. Calculate or read total height according to the instrument method.
7. Repeat the measurement by another observer.

## Basic tangent method
When the base is at the observer's horizontal reference:

`H = d × tan(θ)`

When separate top and base angles are used:

`H = d × [tan(θ_top) − tan(θ_base)]`

Use the sign convention required by the instrument or field protocol.
