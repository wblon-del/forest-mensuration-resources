# Practical 3: Fixed-Area Stand Inventory

## Objective
To establish a fixed-area sample plot, measure trees, and estimate stand density and basal area per hectare.

## Equipment
GPS, compass, measuring tape, diameter tape, height instrument, plot markers, tree tags/numbering materials, field sheet or mobile data form, calculator.

## Procedure
1. Define the plot size and sampling location before entering the plot.
2. Establish the plot boundary using the adopted protocol.
3. Assign a unique plot identifier.
4. Enumerate eligible trees using a consistent boundary rule.
5. Measure species and DBH for each tree.
6. Measure height for the required subsample or all trees, depending on the study design.
7. Record unusual stems and boundary decisions.
8. Check the field sheet before leaving the plot.

## Core calculations

`Trees/ha = Number of eligible trees / Plot area (ha)`

`BA_tree = π × DBH² / 40,000`

`BA/ha = Σ BA_tree / Plot area (ha)`
