# Module 3: Tree Height Measurement

## Learning objectives

Students should be able to distinguish important tree-height variables and explain direct and indirect methods of measurement.

## 3.1 Types of height

- **Total height:** vertical distance from the defined ground reference to the highest living part of the tree.
- **Merchantable height:** stem length considered usable for a specified product or measurement rule.
- **Bole height:** height to a specified stem point such as the first major branch, depending on the protocol.

## 3.2 Direct measurement

Small trees can sometimes be measured directly using a graduated pole. Direct methods become impractical as tree size increases.

## 3.3 Indirect measurement

Clinometers, hypsometers and laser instruments commonly use angles and horizontal distance to estimate height.

For a simple tangent method with the instrument and tree base at the same elevation:

**H = d(tan α + tan β)**

where:

- H = tree height
- d = horizontal distance from observer to tree
- α = angle to the top
- β = angle to the base when the base is below the observer; use the appropriate signed-angle convention for the instrument/protocol.

The formula and sign convention must be adapted when observer and tree base are at different elevations.

## 3.4 Example

An observer stands 20 m horizontally from a tree. The angle to the top is 42° and the angle to the base is 5° below horizontal.

Using the simple tangent method:

H = 20[tan(42°) + tan(5°)]

H ≈ 20(0.9004 + 0.0875) ≈ **19.76 m**.

## 3.5 Sources of error

- incorrect horizontal distance;
- sighting the wrong tree top;
- incorrect base point;
- sloping terrain;
- leaning trees;
- instrument calibration or operator error; and
- using a tangent formula without accounting for unequal elevations.

## Practical activity

Measure the heights of 10 trees using a clinometer or hypsometer. For five trees, repeat the measurement from a different distance and compare results.

## Discussion

Why can measuring the highest visible point rather than the true tree top produce a biased estimate?
