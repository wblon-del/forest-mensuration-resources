# Sample Datasets and Data Tools

This folder contains small teaching datasets and guidance for classroom analysis.

## Suggested datasets

1. `sample_tree_inventory.csv` — plot, tree, species, DBH, height and status.
2. `sample_growth_inventory.csv` — repeated measurements for growth exercises.
3. `sample_biomass_inventory.csv` — DBH, height and wood-density variables for allometric exercises.

## Analysis workflow

Students should keep raw observations unchanged, create a documented cleaned dataset, calculate derived variables, summarize by plot/species and produce simple tables and graphs.

## Suggested software

The exercises can be completed in spreadsheet software. R or Python may be used for reproducible analysis.

## Quality control

Check missing values, duplicate identifiers, units, plausible ranges and unusual observations against original field records.
