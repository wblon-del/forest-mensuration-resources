# Data Analysis Exercises

## R exercise
Use `r_forest_mensuration_analysis.R` with `data/sample_tree_inventory.csv`.

Students should:

1. import the data;
2. calculate individual-tree basal area;
3. summarize trees and basal area by plot;
4. expand results to per-hectare values;
5. inspect the diameter distribution;
6. plot height against DBH; and
7. summarize species composition.

## Extension tasks

- Calculate mean height by species.
- Create diameter classes at 10-cm intervals.
- Compare basal area among plots.
- Identify unusually large or small observations and verify them against the original data.
- Adapt the script for the repeated-growth dataset.

## Reproducibility rule
Never overwrite the raw CSV. Save cleaned data and derived outputs separately and document any correction.
