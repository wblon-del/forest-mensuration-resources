# Forest Mensuration Teaching Resources

A complete, modular teaching resource for **Forest Mensuration**, designed for forestry lectures, tutorials, field practicals, assessment and independent study.

## Course purpose
Forest mensuration provides the quantitative foundation for measuring trees and forest stands. This repository brings together lecture notes, formulas, worked examples, field practicals, exercises, assessments and lecturer guidance in one structured resource.

## Learning outcomes
By the end of the course, learners should be able to:
- explain the principles and applications of forest mensuration;
- measure DBH/circumference and tree height using appropriate field methods;
- calculate basal area, stand density and diameter distributions;
- estimate individual-tree and stand volume using appropriate methods;
- explain stem taper, tree form and form factor;
- calculate and interpret basic growth and yield measures;
- design a basic forest inventory sampling approach;
- estimate biomass and carbon using appropriate validated models;
- identify field and data-processing errors; and
- communicate inventory results clearly and responsibly.

## Suggested course structure
The material is organized for a 14-week course with lectures, tutorials, field practicals, midterm assessment, an inventory assignment and final examination.

## Recommended teaching approach
Use **concept → demonstration → worked example → student practice → field application → interpretation**. Students should record units and explain whether a result is realistic.

## Bhutan application
Examples can be adapted to Bhutanese forest types, plantations, community forests and forest-management regimes. For operational applications, use the applicable approved local/institutional volume and biomass equations and measurement protocols.

## Quality and responsible use
These materials are educational resources. Field measurements should follow institutional safety requirements and approved forestry protocols. Volume and biomass models should only be applied within their appropriate calibration and validity ranges.

## Repository status
The core teaching package is established. Future additions can include photographs, diagrams, local datasets, spreadsheet calculators, R/Python examples, translated materials and institution-specific assessment templates.
